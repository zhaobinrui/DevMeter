# DevMeter 隐私说明

适用版本：0.2 系列。应用内「设置 → 帮助与隐私 → 阅读隐私说明」可离线阅读相同数据范围说明。

## 本机处理的数据

DevMeter 读取 AI Provider 提供的额度窗口、重置时间和可用 Credits。Codex 邮箱与套餐信息
仅在内存中用于生成本机加盐的账户分组，不保存邮箱、登录令牌、提示词、代码或完整会话。
账户分组只用于本机历史归属，不与 Widget、Kindle 或反馈服务共享。
Codex 自身的登录及凭据由 Codex 管理；清除 DevMeter 历史不会退出 Codex 账户。

应用偏好保存在本机。DevMeter 不监控或保存剪贴板历史；只有主动点击复制时才写入剪贴板。

## 历史和保留

Codex 历史只保存额度数字、窗口时间和本机账户分组。默认保留 30 天，可选 7/90 天；
五分钟内合并采样，最多 30,000 条、16 MiB。组织账户、未知套餐或缺少可靠身份时不记录。
可以暂停新增记录或清除全部历史。未解锁或失去 Pro 不会锁住已有历史、保留设置或清除入口。

Claude 状态行接入仅处理主动配置的本地输入，保留两个订阅窗口及接收时间。
原始 JSON、凭据、项目路径和会话文件不落盘，不额外请求模型，也不生成 Claude 账户历史。
可单独清除最近快照；若仍保留 Claude 中的状态行配置，下次事件会重新生成。
要停用接收，请同时移除该配置。

## Widget 和 Kindle

Widget 通过本应用的 App Group 读取最近额度、Credits、来源及时间，不读取账户凭据和历史。
最近快照在共享容器中保留，后续刷新会替换。卸载应用不代表系统自动清除所有偏好或共享容器。

Kindle 服务默认关闭。主动启用后，同一局域网中持有配对地址的人可查看只读额度页面；
配对地址包含随机令牌，请勿公开分享。停用 DevMeter 或退出应用会停止采集与本应用的局域网服务。

## 联网和第三方

DevMeter 不设额度上传服务器，不包含行为追踪或自动诊断上传。
Codex CLI 可能连接其服务，Apple 处理商店购买；直接分发预览仅在配置更新源后由 Sparkle
请求更新。主动打开反馈入口时，浏览器访问 GitHub。各服务适用其各自的隐私政策。

## 权限与清除

系统通知默认关闭，只在主动开启时申请 macOS 权限；可在 macOS 设置中撤回。
DevMeter 设置提供停用采集、暂停历史、清除全部历史、清除 Claude 快照和关闭 Kindle 的入口。
这些操作针对 DevMeter 自己的数据，不清除 Provider 自身保存的登录信息或内容。

## 反馈与联系

通过 [GitHub Issues](https://github.com/zhaobinrui/DevMeter/issues) 联系项目维护者。
反馈内容由你选择并提交，公开 Issue 对其他人可见；请不要粘贴令牌、邮箱、私密代码或配对地址。

「复制支持信息」仅复制应用版本、系统版本、来源名称和通用状态，不包含账号、额度数字、
错误原文、路径或配对令牌。它不会自动打开提交表单、附加信息或发送反馈。
